# Conditional transport-qualified grasp refinement

The lift objective does not test downstream retention. On the first eight TRAIN layouts, all40 learned handovers passed but only31/40 clean teacher routes retained the object. Across80 TRAIN cases with three original-start native-SAC preparations each,43 cases had mixed route outcomes despite identical proposal triples;17/20 deterministic failures had a sampled success. The77/80 cases with any successful variant are an oracle coverage bound, not a policy success rate. The sampler alone is not better: sampled failures also occur on26 deterministic successes.

This proposal tests qualifying **grasp supervision** by actual transport. Prior diversity experiments trained carry from varied grasps without refining grasp in this way. The rejected universal pause, velocity gate, slow approach and compact actor are not repeated.

This measures retained teacher transport, not learned navigation or full-task success. No failed case is retried or replaced, and no best variant is chosen per case.

`RecordingGrasp(wrapped,persist)` in `scripts/phase2_grasp_qualified_demos.py` delegates each grasp action once. It copies the actual observation, action, next observation, native reward, termination/truncation and info, then atomically persists the prefix **before returning to the system**. Later posture/transport failures cannot rewrite those tuples. The boundary metadata separately records a caller handover; a successful prefix may correctly end with both native flags false. These files are BC prefixes and are explicitly not directly replay-seedable. Qualification changes only episode-level BC eligibility. Malformed tuples or uncertain costs stop collection; raw shards and all failed attempts remain available.
